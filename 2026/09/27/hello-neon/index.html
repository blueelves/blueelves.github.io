这是 Blue 的第一篇文章。博客用 Hexo 搭建，跑了一套自己写的深色霓虹主题。

为什么要自己写主题

现成的 Hexo 主题很多，但自己写一遍的收获完全不一样：

  • 你会真正搞懂 Hexo 的渲染流程：Markdown → EJS 布局 → 静态 HTML
  • CSS 从零手写，不会背上一个框架的包袱
  • 想加什么就加什么，不用去读别人几万行的源码

代价是得踩一些坑，比如 EJS 里怎么拿站点数据、url_for 为什么必须写、代码高亮的 DOM 结构长什么样。

这套主题有什么

特性 说明
深色霓虹配色 青 / 品红 / 紫渐变，带光晕
动态背景 网格 + 三团缓慢漂移的极光
代码块 带工具栏、语言标识和一键复制
目录 文章内自动生成，滚动时高亮当前章节
响应式 手机上折叠成汉堡菜单
零外部依赖 不加载任何字体或 CDN，离线可用

一段代码长这样

行内代码也可以，比如 hexo generate、npm install、_config.yml。

行内代码与引用

有时候需要强调一个配置项，比如把 line_number 设成 false，代码块会干净很多。

写作的意义不在于记录，而在于逼自己把话说清楚。
说不清楚的地方，往往就是没想明白的地方。

接下来写什么

主要是三类：

  1. 编程笔记 —— 学到哪写到哪，重点是踩过的坑
  2. 折腾记录 —— 环境配置、工具链、部署流程
  3. 随手记 —— 一些零散的想法

怎么开始写新文章

文章会生成在 source/_posts/ 目录下，改完保存刷新浏览器即可。
